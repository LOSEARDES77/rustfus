## Approved findings

1. **HIGH: opening the log permanently changes the main form to two columns.** Rules R-03, R-05, C-4. `ui.rs::fit_form` widens tall windows and latches the columns state. The non-scrolling main page also clips tall content. Fix: retain one column and the current width; cap automatic height at available screen space and allow vertical scrolling.
2. **MEDIUM: Image Option is unwanted in the requested main form.** Rules R-26, C-3 and explicit user direction. The macOS/Linux selector offers only standard installation, followed by a Windows To Go unsupported notice. Fix: hide the row and unsupported notice on every platform, as requested. Core and CLI Windows To Go support is unchanged; its selector is no longer exposed in the GUI.

Approval: the user explicitly requested both fixes and selected review after the work. No other audit findings authorize changes.
